## Recommended third-party skills

A curated index of skills and collections created and maintained by other authors. These projects are installed separately from Skillpper; each project's repository is the source for its documentation, requirements, license, and updates.

| Project | Author | What it helps with | Installation |
| --- | --- | --- | --- |
| [IP as Logo](https://github.com/s1dashu/ip-as-logo-skill) | [s1dashu](https://github.com/s1dashu) | Create simple, rounded mascot logos with an image-generation agent. | `npx skills@latest add s1dashu/ip-as-logo-skill` — see the [requirements](https://github.com/s1dashu/ip-as-logo-skill#agent-compatibility). |
| [Skills for Real Engineers](https://github.com/mattpocock/skills) | [Matt Pocock](https://github.com/mattpocock) | A collection for clarifying requirements, planning changes, test-driven development, debugging, and software design. | `npx skills@latest add mattpocock/skills` — follow the repository's [installation guide](https://github.com/mattpocock/skills#installation-30-second-setup), including its setup skill. |
| [gstack](https://github.com/garrytan/gstack/tree/main) | [Garry Tan](https://github.com/garrytan) | A collection of workflows for product planning, design reviews, code reviews, browser QA, and releases. | Follow the project's [setup instructions](https://github.com/garrytan/gstack/tree/main#install--30-seconds) for your agent; gstack includes tooling that requires its own setup. |
| [Superpowers](https://github.com/obra/superpowers) | [obra](https://github.com/obra) | A methodology and collection of skills for brainstorming, planning, test-driven development, debugging, and systematic delivery with coding agents. | Follow the repository's [installation guide](https://github.com/obra/superpowers#installation) for your agent; installation differs per harness. |
| [Ponytail](https://github.com/DietrichGebert/ponytail) | [Dietrich Gebert](https://github.com/DietrichGebert) | Keeps the agent on the laziest solution that works: reuse existing code, stdlib, and native platform features before writing anything, plus review, audit, and debt-ledger companion skills. | Follow the per-agent [install guide](https://github.com/DietrichGebert/ponytail#install) (plugin for Claude Code and Codex, `opencode.json` plugin entry for OpenCode, or a copied rules file for Cursor, Windsurf, and others). |
